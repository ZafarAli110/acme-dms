# Plans

One file per ticket in progress, written by the `ticket` skill: the open questions first, then the ticket's
requirements as a checklist, the decisions taken, the shape of the change (files and signatures, no bodies), the
steps, each with the check that proves it, and a log. About 150 lines at most: a plan is for a person to read. It lets
work continue after the conversation is compacted, the session is restarted, or someone else picks it up. A
session-start hook lists the plans that still have unchecked steps.

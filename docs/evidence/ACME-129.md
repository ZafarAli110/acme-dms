# ACME-129: The busy morning on one ordinary database: cheap totals, pages and searches

Verified 2026-11-09 on final (on 8680d7f, the fixes below uncommitted), with the large sample data (Northside about
1.6 million customers), on `bun run start:prod --load-test` (4 copies). The verifier checked every requirement in the
running system and returned FAIL for two reasons:

- A search with 26 to 100 matches showed its exact number, where the ticket says "1–25 of many".
- The work per request at the same rate had not been measured on the current build.

Both are fixed or measured below. Its three smaller findings:

- Sending `after` with `last` answered "request must be a number": fixed.
- The French API message wrote "10,000": fixed.
- "The Export button has no accessible name": not a bug. The page snapshot leaves the name out, but Playwright finds
  `button "Export to Excel"` by its name.

`api` is `bun run api as <user> --location <name> --body GET /api/dealership/v1/…`. Real counts come from read-only
SQL on the running Postgres.

## What these checks don't prove

- **3,300 a second itself.** This laptop sends and serves the load at once and stops near 1,000 a second; the ticket
  compares work per request. A person runs the full rate from a second machine.
- **A warm database.** The 200/s run came straight after a restart: its p95 (99 ms) is above the Log's 34 ms from a
  warm one. The share of work is the ticket's measure, not the tail.
- **The 10 s stock value across 4 copies under load.** Seen from one client; each copy keeps its own value. A test
  that changes stock and reads every copy would prove the limit.
- **Keyset deep in a list with empty sort values.** Pages 1–3 and the end were compared, not the middle of company,
  email or phone where the empty run begins; the handler test covers it but shares the code's assumptions.
- **A cursor replayed after its row's sort value changed.** Not tried; needs a test.
- **"About" after bulk changes before Postgres updates its statistics.** Only today's statistics were checked.

## What these checks don't prove

- A save's refresh of the total was not done live (the checks change no data); the code and the key test cover it.
- Deleted customers are left out of the count in the handler test only: the large sample data has none.
- A user without `customers.read` is refused by the guard's test; no demo role lacks it, so not live.
- 200 a second is a laptop's rate, with the test sending and the system serving on one machine; 3,300 a second needs
  ACME-117's later steps and an environment shaped like production.

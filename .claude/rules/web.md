# Web

- **Routes:** each page is a route module that loads with `clientLoader` and saves with `clientAction`.
- **Forms:** schema → mapper → form → page; the `build-form-page` skill has the steps.
- **Text:** every text the user sees is translated, in en and fr.

The full rules: `docs/standards/web-architecture.md`.
